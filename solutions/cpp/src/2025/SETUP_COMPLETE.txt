================================================================================
  QUICK START
================================================================================

1. CONFIGURE THE PROJECT:
   cmake --preset clang-linux-debug

2. BUILD ALL TARGETS:
   cmake --build cmake_build_clang-linux-debug

3. RUN TESTS:
   ./cmake_build_clang-linux-debug/bin/logic.tests

4. RUN SOLVER:
   ./cmake_build_clang-linux-debug/bin/runner

5. IN VS CODE:
   - Press Ctrl+Shift+B to build
   - Press F5 to debug
   - Cmd+Shift+P > "CMake: Run Tests" to test
   - Cmd+Shift+P > "Tasks: Run Task" to see available tasks

================================================================================
  TROUBLESHOOTING
================================================================================

If build fails:
  rm -rf cmake_build_clang-linux-debug
  cmake --preset clang-linux-debug
  cmake --build cmake_build_clang-linux-debug

If tests don't run:
  - Verify gdb is installed: sudo apt install gdb
  - Check input files exist in resources/2025/*/

If VS Code doesn't recognize CMake:
  - Install C++ Extension Pack (ms-vscode.cpptools-extension-pack)
  - Install CMake Tools (ms-vscode.cmake-tools)
  - Reload VS Code window
